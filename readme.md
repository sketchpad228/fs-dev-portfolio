# Developer Portfolio Project  
**Build. Design. Deploy.**

Your tech career starts with how you present yourself. In this project, you will design and build a fully responsive, personalized developer portfolio that showcases your story, your skills, and your future projects.

You will use **HTML, CSS, and Flexbox (required)**.  
You may use **Bootstrap or Tailwind (optional but encouraged)**.

By the end, your portfolio will be deployed live and publicly accessible.

---

## Project Objectives

By completing this project, you will:

- Structure a multi-section website using semantic HTML
- Apply CSS styling with clean layout principles
- Use Flexbox for responsive layouts
- Implement mobile-first design
- Optionally integrate a UI framework (Bootstrap or Tailwind)
- Deploy a live site (GitHub Pages, Netlify, or similar)
- Present a professional developer identity

---

## Required Sections

### 1) Navigation Bar

- Responsive navigation
- Links scroll to sections (anchor links)
- Must use Flexbox
- If using a framework, you may use its navbar component

---

### 2) Hero Section

Include:

- Your name
- Professional title (e.g., Software Engineer, Full Stack Developer)
- Short 1–2 sentence introduction
- Call-to-action button (e.g., “View My Work”)

Layout requirements:

- Must use Flexbox
- Looks clean on mobile and desktop

---

### 3) About Me

Include:

- 1–3 paragraphs
- Professional summary
- Optional headshot image

Layout requirements:

- Responsive layout (image + text stack on mobile)
- Clean spacing and readable typography

---

### 4) Skills Section

Must include at least:

- Frontend skills
- Backend skills (if applicable)
- Tools/Technologies

Suggested layout options:

- Cards
- Grid
- Flex rows

Requirements:

- Must use Flexbox
- Responsive layout (wrap or stack cleanly)

---

### 5) Projects Section

Include at least **2 project cards** (placeholders allowed).

Each project must include:

- Project title
- Short description
- Technologies used
- GitHub link (placeholder allowed)
- Optional live demo link

Layout requirements:

- Use Flexbox
- Stack vertically on mobile
- Align evenly on larger screens

---

### 6) Contact Section

Must include:

- Clickable email (`mailto:`)
- LinkedIn link (placeholder allowed)
- GitHub profile link
- Optional contact form (HTML only required)

---

### 7) Footer

- Your name
- Current year
- Copyright
- Optional social links

---

## Design Requirements

- Mobile-first approach
- Clean spacing and alignment
- Consistent color scheme (2–3 primary colors max)
- Proper use of margins and padding
- Readable typography
- No broken layouts when resizing
- No horizontal scrolling

---

## Flexbox Requirements

You must use Flexbox for:

- Navbar layout
- Skills layout
- Projects layout
- At least one additional layout of your choice

You must demonstrate usage of:

- `display: flex`
- `justify-content`
- `align-items`
- `flex-direction`
- `flex-wrap`

---

## Responsive Requirements

- Include proper viewport meta tag
- Use at least one media query breakpoint
- Layout must adapt at larger screen sizes
- No horizontal overflow

Example breakpoints:

- 768px
- 1024px

---

## Deployment Requirements

You must:

- Push code to GitHub
- Deploy live using:
  - GitHub Pages
  - Netlify
- Submit live URL
