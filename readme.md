# Challenge: Responsive Account Creation Form

## Goal

Recreate the **Account Creation** page shown in the provided reference images.

Your page should closely match the design and adapt between **desktop and mobile screen sizes**.

You may complete this challenge using either:

- HTML + CSS + Flexbox
- HTML + Bootstrap

---

## Requirements

Your page should include:

- A blue header section
  - "Account Creation" heading
  - Short description
- A centered form card
- Form fields for:
  - First name
  - Last name
  - Date of birth
  - Social Security Number
  - Phone number
  - Address
  - City
  - State
  - ZIP code
- Terms agreement checkbox
- "Create Account" button

---

## Responsive Layout

### Desktop

Use the reference image to create the desktop layout.

- First name and last name should appear side-by-side
- Date of birth and SSN should appear side-by-side
- City and State should appear side-by-side
- Other inputs should take the full available width
- The form should be centered on the page

### Mobile

At smaller screen sizes:

- All form fields should stack vertically
- The form should take up most of the available screen width
- Maintain appropriate padding and spacing

---

## Styling

Try to match the reference as closely as possible, including:

- Colors
- Spacing
- Input sizes
- Rounded corners
- Form card shadow
- Typography
- Responsive behavior

You do **not** need to make the form functional.

---

## Bootstrap Option

If using Bootstrap, try to use Bootstrap classes wherever possible instead of writing custom CSS.

Consider using:

- Containers
- Flex/Grid utilities
- Spacing utilities
- Responsive breakpoints
- Form controls
- Buttons
- Background/text utilities
- Shadows
- Borders and rounded corners

Some custom CSS is allowed when Bootstrap does not provide exactly what you need.
